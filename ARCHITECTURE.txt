SECURITY MODEL:

  Client IP (from socket or X-Forwarded-For)
       ↓
  ACL Match (127.0.0.1/8, 192.168.0.0/16, etc.)
       ↓
  Permission Check (can_api? requires "api" in allow list)
       ↓
  Rate Limit Check (10 requests per 60 seconds)
       ↓
  Request Timeout Check (10 seconds max body)
       ↓
  Handler execution
       ↓
  Response (200/201/4xx/5xx)

CONCURRENCY MODEL:

  Client 1 ─┐
            ├─→ [asyncio event loop]
  Client 2 ─┤   - Handles multiple clients concurrently
            ├─→ - Non-blocking I/O
  Client 3 ─┤   - Lock-free reads (thread-safe Zone operations)
            │   - Atomic writes (threading.RLock in Zone._lock)
            └─→
  
  Benefits:
  - Thousands of concurrent clients
  - No thread context switching overhead
  - Better resource utilization
  - Responsive API even under load

CACHING & INVALIDATION:

  Request hits API → Zone operation (add/modify/delete)
                       ↓
                    Cache.invalidate(qname, qtype)
                       ↓
                    Remove matching entries
                       ↓
                    Next DNS query will re-fetch
